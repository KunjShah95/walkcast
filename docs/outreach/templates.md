# Outreach templates

Five short messages, one per segment in [`../BRAND-GROWTH-PLAYBOOK.md`](../BRAND-GROWTH-PLAYBOOK.md). Each one:

- is written to one person, so replace every `[bracket]` with something true about them;
- puts the value in the first two lines and asks for one small thing;
- makes "no" easy;
- carries one link with UTM parameters: `?utm_source=<segment>&utm_medium=outreach&utm_campaign=<yyyy-mm>`.

If you cannot fill a bracket with something real, do not send the message. A line like "I loved your recent
post" with no post behind it is worse than silence.

---
